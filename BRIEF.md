## Что мы строим

**SewCalc** — одностраничный сайт с калькулятором стоимости производства коллекции одежды.

- **Тип продукта:** Landing page + интерактивный калькулятор
- **Аудитория:** Малые модные бренды, дизайнеры, байеры — ищут швейное производство от 30 единиц
- **Боль клиента:** Не знают стоимость пошива до обращения, боятся звонить «вслепую»
- **Цель проекта:** Портфельный кейс для вайбкодера + демо для потенциальных клиентов ателье

## Структура страницы (8 секций)

### 01 — Nav (шапка)
- Логотип `SewCalc` слева (Cormorant Garamond)
- Меню: Производство / Расчёт / Как работает / Контакт
- Кнопка «Рассчитать стоимость» — акцентный цвет `#b8862a`
- **Sticky** при скролле, фон `#f7f3ed` с тонкой тенью

### 02 — Hero (первый экран)
- Фон тёмный `#2b231a`
- **Левая колонка:**
  - Надпись-кикер: `Швейное производство · B2B`
  - Заголовок (Cormorant Garamond, italic, крупный): *«Ваша коллекция начинается с точного расчёта»*
  - Подзаголовок: объяснение ценности в 2 строки
  - CTA-кнопка: «Рассчитать коллекцию» — акцентный цвет
- **Правая колонка:**
  - Карточка-превью калькулятора (мини-версия с 2–3 полями и результатом)

### 03 — Из чего складывается цена
- Фон светлый `#f7f3ed`
- Заголовок секции + 4 карточки горизонтально:
  - 🧵 Работа мастеров
  - 🪡 Материалы
  - 📦 Накладные расходы
  - ⚡ Срочность
- Каждая карточка: иконка + название + короткое объяснение

### 04 — Калькулятор (главная секция)
- Фон `#ede8df`
- Мультишаговая форма — 4 шага с прогресс-баром
- Детальное описание — см. раздел «Логика калькулятора» ниже
- После результата — форма заявки

### 05 — Как это работает
- 3 шага горизонтально:
  1. **Рассчитайте** — введите параметры коллекции
  2. **Обсудите детали** — мы свяжемся в течение часа
  3. **Получите коллекцию** — в срок и по смете
- Горизонтальный таймлайн с акцентными номерами

### 06 — Цифры производства
- Фон тёмный `#2b231a`
- 3 крупных числа с анимацией счётчика при скролле:
  - **12+** лет на рынке
  - **400+** коллекций выпущено
  - **от 30** единиц — минимальный тираж
- Под каждым числом — короткое пояснение

### 07 — FAQ (частые вопросы)
- Аккордеон — 6 вопросов:
  1. Каков минимальный тираж?
  2. Могу я принести свою ткань?
  3. Сколько времени занимает пошив?
  4. Делаете ли вы примерки?
  5. Как происходит оплата?
  6. Что если результат мне не подойдёт?

### 08 — Footer + финальный CTA
- Фон тёмный `#2b231a`
- Цитата в кавычках (Cormorant Garamond, italic):
  *«Мы считаем каждую деталь — чтобы вы могли считать на нас»*
- Форма заявки: Имя / Название бренда / Telegram
- Кнопка «Отправить заявку»
- Соцсети + копирайт

## Логика калькулятора

### Параметры (4 шага)

**Шаг 1 — Тип изделия**
| Вариант  | Коэффициент работы |
|----------|--------------------|
| Топ      | 1.0                |
| Брюки    | 1.2                |
| Платье   | 1.5                |
| Жакет    | 1.8                |
| Пальто   | 2.2                |
| Другое   | 1.4                |

**Шаг 2 — Тираж**
| Вариант   | Коэффициент тиража |
|-----------|--------------------|
| 30–50 ед. | 1.15 (малый)       |
| 51–100    | 1.00 (стандарт)    |
| 101–300   | 0.90 (оптовая скидка) |
| 300+      | 0.80 (крупный опт) |

**Шаг 3 — Материал и сложность**

*Материал (стоимость метража на единицу, ₽):*
| Вариант         | Цена метра | Расход |
|-----------------|------------|--------|
| Ваш материал    | 0          | —      |
| Хлопок          | 300        | 2 м    |
| Трикотаж        | 400        | 1.5 м  |
| Шёлк            | 900        | 2 м    |
| Деним           | 500        | 1.8 м  |
| Пальтовая ткань | 1200       | 2.5 м  |

*Сложность конструкции (коэффициент):*
| Вариант              | Коэффициент |
|----------------------|-------------|
| Простая              | 1.0         |
| Средняя              | 1.3         |
| Высокая (декор, подкладка) | 1.7  |
| Кутюр (ручная работа)| 2.2         |

**Шаг 4 — Срочность**
| Вариант              | Наценка |
|----------------------|---------|
| Стандарт (6 недель)  | +0%     |
| Быстро (3 недели)    | +20%    |
| Срочно (1 неделя)    | +50%    |

### Формула расчёта

```
Базовая работа = 1500 ₽ × К.изделия × К.сложности
Материал       = цена_метра × расход_метров
Накладные      = (работа + материал) × 0.15

Итого/ед.      = работа + материал + накладные
С тиражом      = итого × К.тиража × К.срочности

Диапазон показываем:
  Минимум = итого_с_тиражом × 0.85
  Максимум = итого_с_тиражом × 1.15
```

### Результат — разбивка по строкам

```
Работа мастеров:    X ₽ — Y ₽  за единицу
Материалы:          X ₽ — Y ₽  за единицу
Накладные расходы:  X ₽ — Y ₽  за единицу
─────────────────────────────────────────
Итого за единицу:   X ₽ — Y ₽
Итого за партию:    X ₽ — Y ₽  (тираж × стоимость)
```

После результата сразу появляется CTA:
«Хотите точный расчёт под вашу коллекцию? Оставьте заявку — ответим в течение часа.»
